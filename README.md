## Fluxo de estudo

1. Selecionar uma fonte identificável: título, autor, data e link.
2. Registrar a pergunta que a leitura deve esclarecer.
3. Distinguir afirmações da fonte, interpretação pessoal e dúvidas.
4. Revisar as respostas do NotebookLM à luz dos materiais originais.
5. Salvar a síntese e os próximos passos neste repositório.
